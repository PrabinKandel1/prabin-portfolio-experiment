# Prabin Portfolio Experiment

An earlier portfolio experiment by Prabin Kandel, preserved as part of my learning journey in web development during Class 12. This repository is an archived code experiment, not my current portfolio website.

## What is inside

- HTML page and section layouts
- CSS styling, theme tokens, responsive rules, and animations
- JavaScript interactions, navigation, gallery, certificates, and local assistant demo
- Image assets and translation data

## Run locally

This is a static website. Open `index.html` in a browser, or serve this folder with a local static HTTP server for a more representative test. Some external libraries and embedded features require an internet connection.

## Contact form

EmailJS credentials have been replaced with placeholders in this archived copy. Configure your own EmailJS settings before enabling form submission. Never commit private service credentials or other secrets.

## Status

Archived experiment. It is kept for historical reference and is not the active portfolio deployment.
